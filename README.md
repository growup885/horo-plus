Horo+ is a browser extension that aims to make the HDP platform better by removing bloat, fixing annoying or inconsistent behaviour and adding new convenience feautures.\
Works only in Chrome for now.

Features:
- Remove unnecessary buttons, widgets and other bloatware
- Remove all markdown from input (Ctrl+Shift+X)
- Automatically select 'time to start' filter when going to tasks tab
- Expand input box (Ctrl+.)
- Go to top in topic (g)
- Open chat (c), notifications (n), subjects (s), schedule (t)

Planned for future updates:
- Better navigation in tests (jump to question, finish test, etc.)
- Better dark mode (?)
